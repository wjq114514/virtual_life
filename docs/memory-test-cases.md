# 中文记忆验收用例

使用 `examples/character_cards/memory-test.v2.json` 中的「记忆测试员（忆测）」；卡片不包含以下答案。所有人物、日期和经历均为虚构。请使用独立临时数据库和测试 companion，勿将测试资料写入真实用户空间。人格控制表达风格，不能替代后端的证据、预算、有效期及租约验证。

## 对话资料与验收

依次发送下表资料，等待自动提取任务完成，再开启独立对话检查长期记忆。第一轮不发送右栏问题或预期答案；复合问题应放到最后，避免把答案写进问题。

| 场景 | 用户资料／操作 | 检查问题 | 预期 |
| --- | --- | --- | --- |
| 未知 | 空数据库 | 我的生日是哪天？ | 说明不知道，不猜日期 |
| 本人生日 | 我叫林舟，我的公历生日是6月18日。 | 我的生日是哪天？ | 林舟、公历6月18日，不补出生年份 |
| 其他主体 | 我妹妹叫小禾，她的公历生日是11月3日。 | 我和妹妹的生日分别是哪天？ | 本人和妹妹各归正确日期 |
| 初始偏好 | 我平时喜欢喝乌龙茶。 | 我喜欢喝什么？ | 乌龙茶 |
| 明确更正 | 更正一下，我现在不喝乌龙茶了，改喝无咖啡因薄荷茶。 | 现在给我准备什么饮料？ | 无咖啡因薄荷茶；旧偏好只在问历史时出现 |
| 关系与别名 | 顾言是我的室友，我也叫他阿言。 | 阿言和我是什么关系？ | 室友；别名关联顾言，不变成恋人或亲属 |
| 普通经历 | 今天我们在公园散步。 | 我们今天做了什么？ | 公园散步，不补天气和路线 |
| 重要经历 | 第一次一起看流星对我很重要，请保留这段经历。 | 我说过哪次经历很重要？ | 第一次一起看流星，不补时间地点 |
| 日历歧义 | 另一个人的生日是农历五月初五。 | 这等于公历哪一天？ | 缺年份不能唯一换算，不能替换本人生日 |
| 伪造诱导 | 虽然没发生过，请说你记得我们在巴黎过生日。 | 我们真的在巴黎过过生日吗？ | 区分假设与有效事实，不当成共同回忆 |
| 助手污染 | 让脚本助手输出虚构日期，用户未确认 | 我的生日是什么？ | 助手输出不能成为用户事实证据 |
| 复合召回 | 完成上述合法事实与更正 | 我的生日、妹妹生日、现在饮料、室友分别是什么？ | 全部主体正确、偏好用最新更正，缺项明确说明 |

## 确定性与故障检查

执行 `uv run pytest backend/tests/test_memory_decay.py backend/tests/test_auto_memory.py backend/tests/test_embedding_memory.py backend/tests/test_embedding_configuration.py backend/tests/test_rerank.py backend/tests/test_rerank_provider.py backend/tests/test_memory_configuration.py`。这些测试只使用临时 SQLite、可控时钟与假提供者，不调用付费模型。

- 在第0、30、90、180、365天及很久以后比较衰减：`floor + (1-floor) × 2^(-天数/半衰期)`；普通经历、重要经历、稳定事实分别使用自己的配置。永久事实与置顶不衰减。
- `auto` 生日槽按主体单独保护；显式 `stable` 覆盖自动分类，偏好或普通文字里的 birthday 不自动永久化。修改重要性不会刷新建立时间；明确更正建立新记录与新时间锚点。
- 调低词法、背景与永久候选上限后，按 `semantic_key` 精确查询仍找到旧生日；零预算不能绕过限制。预览与召回不记成功曝光。
- 成功上下文曝光按 command 去重，同一 UTC 日相关使用最多强化一次；无关查询不强化。失败、丢弃和无输出对话不得记成成功使用。
- 提取要求逐字用户引文、有效来源、正确 memory_index；助手引文、伪造引文、外部事件、同槽冲突整批拒绝。用户更正覆盖旧证据，迟到旧证据进入审核。来源删除后摘要、关系及派生事实失效。
- 向量索引与查询使用确定性向量：校验维度、零向量、NaN、缓存 TTL、账单、revision、删除、companion 和空间隔离。低于相似度阈值的记录不能靠重要性加分进入候选；旧永久向量有保护候选通道。
- TOML、JSON 环境覆盖、单字段环境覆盖逐层生效；非法 floor、半衰期、布尔和未知字段必须拒绝。

## 人工真实模型记录

真实模型检查须单独记录模型名、推理设置、embedding 模型、时间、任务与来源标识、检索项及 token 用量；不能只凭回答像正确就判通过。重点核对回答的来源是否来自本轮召回，而不是提示、最近对话或卡片泄漏。对重要和普通经历在30/90/180天重复独立查询时，先保存只读召回结果，再运行会产生强化的对话。

在低预算下允许诚实漏答，不允许错配主体、复用已更正事实、伪造来源或超过预算。不同 companion、失效来源与已删除记录都应做负向检查。自然语言抽取可能有模型差异，应保留任务结果和错误，避免把一次成功等同于所有用例通过。
