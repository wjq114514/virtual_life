# 初步接口框架实施计划

目标：将设备建模为 AI 可以迁移的节点，保存同一位陪伴者的活动、相处状态和共同记忆。安卓为首个原生接入目标。先交付可运行的接口框架与节点 SDK。

## 本轮交付

1. FastAPI REST / WebSocket 接口，SQLite 持久化，导出 OpenAPI。
2. 节点注册、心跳、能力描述、节点图与在线判断。
3. 陪伴者状态、共读位置、版本检查、幂等命令、可回放事件。
4. 迁移准备、目的节点 ready、原节点 released、提交或超时恢复。输出权使用短租约和 epoch。
5. 长期记忆存储、来源与去重、受 token 预算约束的本地召回、稳定偏好与共同经历分层、压缩与模型预算接口。
6. Kotlin 节点 SDK 与安卓宿主桥接接口。SDK 可作为 Android 项目的依赖，原生悬浮窗、权限与服务生命周期由宿主适配器承接。
7. 两个节点的完整接力示例，验证阅读上下文与记忆连续性。

## 模块与子代理分工

- 节点协调子代理：`backend/virtual_life/models.py`、`storage.py`、`coordinator.py`、`backend/tests/test_coordinator.py`。负责状态、节点图、迁移、租约、持久事件与命令去重。
- 记忆子代理：`backend/virtual_life/memory.py`、`ports.py`、`backend/tests/test_memory.py`。负责分层记忆、检索预算、来源、语义键修正、成本接口与模型/感知扩展端口。
- 安卓节点子代理：`clients/android-node/`。负责 Kotlin 协议类型、REST / WebSocket 客户端、迁移握手、输出 gate 与宿主桥接接口。
- 主代理：API、设置、项目脚手架、示例、架构与参考调研文档、OpenAPI、跨模块联调与验证。

各代理共享工作目录，只修改自己的文件，不撤销其他代理的改动。编码以 `docs/protocol.md` 为共同合同；合同更改需要先同步其他模块。

## 记忆效果与成本

- 工作上下文随陪伴者状态保存；稳定偏好和共同经历独立持久化。
- 迁移携带当前状态和记忆引用；长期存储统一保存，按需召回。
- 原始来源与事实/偏好保留可追溯关系，压缩结果作为派生内容。
- 共同经历按 episode_key 或来源事件去重；稳定认识用 semantic_key 定位，通过带 revision 检查的显式更正保留历史；重要记忆不会仅因为年久被删除。
- 默认本地检索，不调用付费模型；召回限制条数与估算 token。
- 分批压缩与 embedding 保留接口和预算控制，后续按收益、调用成本与模型精度启用。
- 初版词法检索对同义表达的覆盖有限；语义与长期召回效果需要后续真实样本评估。

## 演进路线

初期模块化单体。后续通过 Repository、ModelProvider、PerceptionProvider、MemoryRetriever 与 NodeBridge 替换实现。持久层需要先抽象仓储接口，再将 SQLite 查询与事务迁移到 PostgreSQL；持久事件可以接事务 outbox 与消息队列；WebSocket 网关、模型任务可独立扩容。

本轮是单用户本地开发框架，使用配置的 bearer token；账号、多用户隔离、设备配对、真实模型接入和 Android APK 属于后续交付。

## 验证重点

迁移后共读上下文不丢失；错误 epoch 与过期 lease 拒绝；旧源未释放时不提交；目的节点离线/超时可恢复；重复请求不重复迁移；数据库重启保留状态和记忆；中文旧记忆可检索；修正偏好不召回旧事实；召回上下文满足预算；节点 SDK 编译及契约一致。

## 自动记忆：摘要与知识图谱融合

2026-10-12，根据用户要求参考 AstrBot LivingMemory、Angel Heart 及配套 Angel Memory，接入完成对话的自动积累。调研核验了批次与空闲触发、摘要/图谱来源、混合检索和失败恢复代码；取舍与源码链接见 [自动记忆](automatic-memory.md)。

新增 AutoMemoryService：完成对话事件、回执与唯一事件入队原子提交；默认四轮或最旧事件等待六十秒触发；原始 episode 本地保存，模型在事务外一次输出稳定认识、摘要与关系，并复用共享 token 预留/结算。结构与用户精确证据校验在派生提交之前进行，已知用量即使结果无效也入账。手动记录、受保护版本和较新证据优先，冲突保留为 needs_review；有冲突的批次不发布摘要。

摘要和图谱依赖源 ID/revision；自动提取的稳定认识还要求至少一个当前有效的证据 episode。无效来源在候选限制前过滤，引用在模型调用前后复检。DELETE 保存来源墓碑阻止后台再生。读时融合词法、摘要与最多一跳关系，保持预算裁剪；人格预览引用包括实际入提示派生项的支持记录。
