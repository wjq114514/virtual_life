# 第三方软件署名

## DDxfy/GPT-FIG

- 项目：<https://github.com/DDxfy/GPT-FIG>
- 版本快照：commit `f5e64c8ffd5e8a468f2b94de69e23fe712b8c77c`
- 许可证：MIT

本仓库复用其 UI 形态与组件划分思路：单 Activity + Jetpack Compose、消息列表与输入框分离、
设置以底部弹层呈现、会话状态用 `StateFlow` 单向驱动。未复制其代码，也未复制其模型接入层；
网络与协议层全部来自本仓库的 `clients/android-node`。
